# Term Definitions

## Grants

What the license permits:

| Value | Meaning |
|-------|---------|
| `commercial-use` | Use for commercial purposes |
| `modifications` | Modify the source |
| `distribution` | Distribute the software |
| `patent-use` | Use patents under the license |
| `private-use` | Use privately |

## Obligations

What you must do (keyed by obligation, values are usage contexts that trigger them):

| Obligation | Meaning |
|------------|---------|
| `include-copyright` | Include copyright and license notice |
| `disclose-source` | Make source code available |
| `network-use-disclose` | Disclose source for network/SaaS use |
| `same-license` | Derivatives must use the same license |
| `same-license--file` | Same license per modified file |
| `same-license--library` | Same license for linked libraries |
| `document-changes` | Document modifications |

## Restrictions

What the license prohibits:

| Restriction | Meaning |
|-------------|---------|
| `commercial-use` | Cannot use commercially |
| `distribution` | Cannot redistribute |
| `modifications` | Cannot modify |

## Disclaimers

What the license does not guarantee:

| Disclaimer | Meaning |
|------------|---------|
| `liability` | No liability for damages |
| `warranty` | No warranty of any kind |
| `patent-use` | No patent rights granted |
| `trademark-use` | No trademark rights granted |

## Categories

| Category | Description |
|----------|-------------|
| `Permissive` | No restrictions on use |
| `Copyleft` | Derivatives must use same license |
| `Copyleft Limited` | Weaker copyleft (file or library scope) |
| `Non-Commercial` | Prohibits commercial use |
| `Proprietary Free` | Free to use but cannot modify/redistribute |
| `Commercial` | Requires purchased license |
| `Source-available` | Source visible but redistribution restricted |
| `Free Restricted` | Free with specific restrictions |
| `Public Domain` | No copyright restrictions |
| `Patent License` | Patent-specific grant |
| `CLA` | Contributor license agreement (not a software license) |
| `Unstated License` | No license stated |
